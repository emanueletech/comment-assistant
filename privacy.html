Emanuele Tech Commenti – Privacy Policy

Last updated: 17 November 2026

Emanuele Tech Commenti is a private tool used only by the owner of the YouTube channel @emanuele_tech to read and reply to comments posted on that channel's videos. It is not offered to other users.

What data it uses

  • Comments on the channel's videos: comment text, the commenter's public display name and channel ID, and the video's title and description, read through the YouTube Data API.
  • The channel owner's authorization: an OAuth token that lets the tool reply to comments on the owner's behalf.

How it is used

  • Comments are used only to draft and post replies on the channel.
  • To draft a reply, the comment and the video's title and description are sent to Anthropic's Claude API. Drafts that need approval are sent to the channel owner through a private Telegram bot.
  • The tool keeps only the IDs of comments it has already handled (for 60 days) and the drafts awaiting approval, on the owner's private server.
  • No data is sold, used for advertising, or shared with anyone else.

Revoking access

Access can be revoked at any time from Google Account → Third-party connections.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
